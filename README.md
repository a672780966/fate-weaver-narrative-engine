# Fate Weaver Narrative Engine

## An Emotion-Environment Driven Multi-Agent Narrative Simulation Architecture

Fate Weaver Narrative Engine is a research-oriented concept repository for exploring long-running AI narrative worlds where stories emerge from simulated lives rather than being directly generated as plots.

The central hypothesis is that believable character behavior should not be driven primarily by semantic memory retrieval. Instead, environmental stimuli and emotional pressure should activate memories, reshape personality tendencies, and produce behavior.

```text
environment -> emotion -> memory emergence -> personality drift -> behavior -> world change
```

This repository is not a runnable implementation yet. It is structured as a paper-style research repository for critique, discussion, and future prototyping.

## 中文简介

Fate Weaver Narrative Engine（命运编织者叙事引擎）是一套面向长期 AI 叙事世界的研究型概念架构。

它不是普通的 AI 写小说工具、多角色聊天系统或角色扮演 Prompt 模板，而是试图探索一种新的叙事模拟范式：故事不是被模型直接写出来，而是由具备情绪、记忆、环境压力、关系网络和人格变化的智能体在世界中生活出来。

核心观点：真正驱动角色行为的不是单纯的记忆检索，而是环境刺激与情绪压力先激活记忆，再推动人格偏移、行为选择和世界变化。

当前仓库以论文研究仓库形式组织，适合与多智能体系统、AI NPC、计算叙事、人工生命、长期记忆与涌现式故事生成方向的研究者交流。

## 日本語紹介

Fate Weaver Narrative Engine は、長期的に持続する AI ナラティブ世界を研究するための概念的アーキテクチャです。

これは通常の AI 小説生成ツールや複数キャラクターのチャットシステムではありません。物語を直接生成するのではなく、感情、記憶、環境からの圧力、人間関係、人格変化を持つエージェントが世界の中で生きることによって、物語が自然に立ち上がる可能性を探ります。

中心となる仮説は、キャラクターの行動を本当に駆動するのは単なる記憶検索ではなく、環境刺激と感情の変化が記憶を呼び起こし、そこから人格の揺らぎ、行動選択、世界の変化が生まれるというものです。

このリポジトリは、マルチエージェントシステム、AI NPC、計算物語論、人工生命、長期記憶、創発的ストーリーテリングに関心を持つ研究者や開発者との議論を目的としています。

## Core Contributions

1. Emotion-environment-memory loop as an alternative to retrieval-first character design.
2. Observer as a narrative compression engine for long-range causal continuity.
3. Fate intervention that amplifies existing internal drift instead of forcing plot.
4. Separation of simulation, cognition, and narration.
5. Minimal prototype design for testing psychological continuity in repeated events.
