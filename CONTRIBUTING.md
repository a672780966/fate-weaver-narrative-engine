# Contributing

This repository is currently a research concept repository.

Useful contributions include:

- critique of the architecture
- related-work suggestions
- terminology improvements
- experimental design feedback
- minimal prototype ideas
- diagrams
- translations

Please keep discussions focused on research clarity, testability, and conceptual precision.

## Suggested Issue Types

- Related work
- Architecture critique
- Experiment design
- Terminology
- Translation
- Implementation sketch
