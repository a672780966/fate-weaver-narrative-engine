# Related Work

## Generative Agents

Stanford's Generative Agents work is the closest conceptual neighbor. It demonstrated believable human-like behavior in a simulated town through memory, reflection, and planning. Fate Weaver builds on this direction but emphasizes emotional inertia, personality drift, and environment-triggered memory emergence.

Reference: [Generative Agents: Interactive Simulacra of Human Behavior](https://arxiv.org/abs/2304.03442)

## AI Town

AI Town is an open-source starter kit inspired by agent town simulations. It provides a practical reference point for social agent environments, though Fate Weaver is more focused on narrative causality and long-form psychological continuity.

Reference: [a16z-infra/ai-town](https://github.com/a16z-infra/ai-town)

## ReAct

ReAct studies the interleaving of reasoning and acting in language models. Fate Weaver is related at the agent-control level, but its main concern is not task completion. It focuses on emotional causality, long-term character change, and narrative selection.

Reference: [ReAct: Synergizing Reasoning and Acting in Language Models](https://arxiv.org/abs/2210.03629)

## Voyager

Voyager explores open-ended embodied agent learning in Minecraft. It is relevant because it treats agents as persistent actors in an environment rather than one-shot responders. Fate Weaver differs by targeting narrative meaning and psychological continuity rather than skill acquisition.

Reference: [Voyager: An Open-Ended Embodied Agent with Large Language Models](https://arxiv.org/abs/2305.16291)
